# Regulated Power Supply PCB Design

## Overview
This project is a regulated DC power supply PCB designed using KiCad.  
The design provides stable DC voltage output for electronic applications.

## Features
- Regulated DC output
- Compact PCB layout
- Easy-to-manufacture design
- Schematic and PCB files included

## Tools Used
- KiCad
- LTspice (optional)

## Project Files
- Schematic design
- PCB layout
- Gerber files
- Source files
